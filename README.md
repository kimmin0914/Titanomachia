# 👾 Titanomachy (거신 토벌전)

**C언어 2차원 배열과 자체 콘솔 렌더링을 활용한 웅장한 보스 레이드 슈팅 게임**입니다. 
단순한 과제를 넘어, 체력 비례 쿨타임 감소, 쫄(Minion) 소환 타임어택, 화면 진동 및 광폭화 등 실제 MMORPG와 탄막 슈팅 게임의 핵심 기믹을 콘솔창에 완벽하게 구현했습니다.

<br>

## 🌟 주요 기능 및 특징 (Features)

* **정교한 물리 엔진 (1바이트 충돌 매트릭스)**
  * 시각적 깨짐과 판정 오류를 방지하기 위해 1바이트 기반의 아스키아트(ASCII Art)를 채택했습니다. 
  * `char map[25][60]` 배열을 기반으로 플레이어, 총알, 유도탄, 보스의 1픽셀 단위 정교한 충돌 판정을 구현했습니다.
* **다이내믹 페이즈 시스템 (Dynamic Phase System)**
  * **Phase 1 (100% ~ 60%):** 거신의 기본 레이저 및 공간 파동 공격
  * **Phase 2 (60% - 심판의 의식):** 보스 무적화 및 광신도 소환. 10초 내 전멸 실패 시 보스 체력 80% 회복 (DPS 체크 기믹)
  * **Phase 3 (30% - 광폭화):** 화면 진동 연출과 함께 쿨타임이 극한으로 감소하는 탄막 생지옥 돌입
* **자체 더블 버퍼링 기법**
  * 콘솔창의 `system("cls")` 사용 시 발생하는 극심한 화면 깜빡임(Flickering)을 잡기 위해, `gotoxy()` 함수를 활용하여 변경된 픽셀만 덮어쓰는 렌더링 최적화를 적용했습니다.

<br>

## 🕹️ 조작법 및 난이도 (Controls & Difficulty)

* **이동:** 방향키 `↑` `↓` `←` `→`
* **공격:** 스페이스바 `Spacebar` (신의 쐐기 발사)
* **난이도:**
  * `Easy` : 기본 레이저 패턴
  * `Normal` : 레이저 + 회피 구멍이 생성되는 공간 파동 기믹
  * `Hard` : 레이저 + 파동 + 플레이어를 끝까지 쫓아오는 추적 유도탄

<br>

## 📊 게임 로직 플로우 차트 (Architecture)

게임의 메인 루프와 인게임 물리 엔진 루프가 맞물려 돌아가는 전체적인 프로그램 흐름도입니다.

```mermaid
graph TD
    A([프로그램 시작 main]) --> B[난수 초기화 및 화면 세팅]
    
    subgraph Main Loop [메인 메뉴 렌더링 루프]
        B --> C[타이틀 화면 출력]
        C -->|2번 입력| D[도움말 및 조작법 출력]
        D --> C
        C -->|3번 입력| E([프로그램 종료 exit])
        C -->|1번 입력| F[난이도 선택]
    end

    F --> G[게임 인게임 데이터 초기화]

    subgraph Game Engine Loop [초당 33프레임 인게임 루프]
        G --> H((프레임 시작))
        H --> I[1. 사용자 입력 처리 handle_input]
        I --> J[2. 물리/패턴 연산 update_logic]
        J --> K[3. 2차원 배열 도화지 렌더링 build_frame]
        K --> L[4. 콘솔 화면 그래픽 출력 draw_frame]
        
        L --> M{승패 조건 검사}
        M -->|플레이어 체력 0| N[게임 오버 연출]
        M -->|보스 체력 0| O[클리어 연출]
        M -->|전투 진행 중| P[30ms 대기 Sleep]
        P --> H
    end

    N -->|아무 키나 입력| C
    O -->|아무 키나 입력| C
